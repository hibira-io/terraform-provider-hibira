# Hibira Provider

[Hibira](https://hibira.io) is a hosted, Pusher-compatible realtime WebSocket service. This provider manages its apps, their webhooks and their push notification (Beams-compatible) credentials, waiting rooms, Hibira Approvals and Hibira Live Chat, so each environment's realtime setup lives in Git with the rest of your infrastructure, and app keys and secrets flow straight into the other resources that need them.

## Authentication

In the Hibira portal, open [API tokens](https://hibira.io/portal/api-tokens) and create a personal access token with **read and write** access (a read-only token can only use the data sources). Set it as `HIBIRA_API_TOKEN`, or pass it to `api_token` from a variable; don't commit it.

A token limited to one app can manage that app's webhooks and push settings, but can't create apps. Destroying apps, Approvals workspaces and webhooks, and rotating secrets, needs a token with **read, write and delete** access; a token can also be limited to some products.

The same token sets up Hibira Approvals and, in the Live Chat workspaces its owner is an owner or admin of, Hibira Live Chat (`hibira_livechat_team`, `hibira_livechat_business_hours`, `hibira_livechat_saved_reply`, `hibira_livechat_knowledge_source`).

## Example Usage

```terraform
terraform {
  required_providers {
    hibira = {
      source  = "hibira-io/hibira"
      version = "~> 0.1"
    }
  }
}

# Make a token with read and write access in the Hibira portal, then
# export HIBIRA_API_TOKEN=hkb_pat_... (or set api_token).
provider "hibira" {}
```

```terraform
resource "hibira_app" "chat" {
  name            = "chat-prod"
  client_events   = true
  allowed_origins = ["https://example.com"]
}

resource "hibira_webhook" "presence" {
  app_id = hibira_app.chat.id
  url    = "https://example.com/hooks/hibira"
  events = ["member_added", "member_removed"]
}
```

## Schema

### Optional

- `api_token` (String, Sensitive) A Hibira API token (`hkb_pat_...`) with read and write access, made on the Hibira portal's API tokens page. Can also be set with the `HIBIRA_API_TOKEN` environment variable.
- `endpoint` (String) The Hibira site URL. Defaults to `https://hibira.io`, or the `HIBIRA_ENDPOINT` environment variable.
- `livechat_endpoint` (String) Hibira Live Chat's address, for the `hibira_livechat_*` resources other than `hibira_livechat_workspace`. Defaults to `https://api.hibira.io/live-chat`, or the `HIBIRA_LIVECHAT_ENDPOINT` environment variable.
